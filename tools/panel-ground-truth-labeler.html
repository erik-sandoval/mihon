Panel Ground Truth Labeler

Open Internal storage/Mihon/panel_flags/bad — the pages you flagged as wrong, the ones worth correcting — or add the .jpg/.json file pairs directly if your browser can't pick a folder (e.g. Firefox for Android). Pages you marked good already have correct detection, so there's nothing to fix there.

Boxes start from what the model detected. Each has its own number and color so you can tell overlapping ones apart — drag corners to resize, drag the box to move it, drag on empty space to draw a new one, tap a box to select it, or pick it from the Panels/Text lists. Hold Ctrl and drag with the mouse to pan. On a page covered in boxes, hold P or T and drag to force-draw a panel/text box on top of whatever's there instead of grabbing it. Hotkeys: with a box selected, P/T set its class and F flips it; otherwise P/T set the class new boxes get drawn as. Delete removes the selected box, arrows change page, Ctrl+Z undoes.

Panels load in the reading order the app's own algorithm would use; drag ⠿ in the Panels list to fix the ones it gets wrong. The exported order is your hand-verified reading order — that's what these files tune. ≠ app order next to the Panels list means this page's ordering disagrees with the algorithm (so it's a useful fixture); auto-order re-applies the algorithm if you want to start over.

Edits are saved to this browser as you go, so you can close the tab and reopen the same folder to pick up where you left off. When you're done, Export all (Ctrl+S) downloads every labeled page as one .zip of .ground_truth.json files — no file-per-page downloads while you work. If the folder opened with live write access, pages also save into it in place as you navigate.
